LES 3 ÉCARTS À CORRIGER

1. COLLECTE PHYSIQUE INCOMPLÈTE
Aujourd’hui, createCollectHarvestAction et completeHarvestTransfer ne manipulent encore réellement que :
- gold
- food

Alors que city_pending_harvest et city_inventory ont déjà :
- wood
- stone
- iron

Je veux que la collecte physique transfère aussi :
- wood
- stone
- iron

Autrement dit :
pending_harvest → city_inventory doit être complet pour les 5 matériaux V1.

2. MAUVAISES COORDONNÉES DANS collect-harvest
Dans la route collect-harvest, le code lit encore les coordonnées depuis :
- access.cityRecord?.worldX
- access.cityRecord?.worldY

Ce n’est pas acceptable.
Le correctif précédent sur checkCityAccess a déjà prévu :
- access.worldX
- access.worldY

Je veux que collect-harvest utilise explicitement les vraies coordonnées retournées par checkCityAccess.

3. TEXTE UI TRANSPORT TROMPEUR
Dans TreasuryPanel, le texte de capacité transport parle encore seulement de :
- or + nourriture

Alors que le backend calcule maintenant la capacité totale sur :
- gold
- food
- wood
- stone
- iron

Je veux que ce texte reflète exactement la règle serveur réelle.

OBJECTIF FONCTIONNEL EXACT

Après ce patch :

1. une ville sans banque peut accumuler en pending :
- gold

- access.worldX
