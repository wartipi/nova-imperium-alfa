OBJECTIF
Je veux 3 changements liés aux interactions sur les cases :

1. L’option `Se déplacer ici` doit apparaître dans le menu d’action de la case, mais seulement quand le déplacement est réellement possible.
2. Le bouton `Se déplacer ici` doit être retiré de la fenêtre d’information de case.
3. La fenêtre d’information de case doit s’ouvrir au **double clic droit**, et non plus au simple clic droit.

IMPORTANT
Ne pas casser :
- le menu d’action de l’avatar au clic droit sur le personnage
- le preview/pathfinding déjà harmonisé
- la logique de confirmation de déplacement existante
- la distinction entre info de case et menu d’action
- le flux serveur-autoritaire de déplacement

CONTEXTE MÉTIER
Le principe attendu est le même que pour `Revendiquer le territoire` :
- une action ne doit être visible que si elle est réellement faisable
- je ne veux pas un bouton visible qui échoue ensuite sans raison
- je veux réutiliser la logique déjà existante autant que possible

CONTEXTE TECHNIQUE
Le projet a déjà :
- une logique de déplacement harmonisée
- un preview de path dans `GameCanvas`
- une validation client qui refuse les destinations non découvertes et les chemins traversant des cases non découvertes
- une fenêtre d’information de case

- une logique existante de confirmation de déplacement

Je veux réutiliser ces briques, pas en recréer.

3. MODIFICATION MINIMALE PROPOSÉE

A. Déplacer l’action `Se déplacer ici` vers le menu d’action de case
Je veux que `Se déplacer ici` soit proposée dans le menu d’action de la case, pas dans la fenêtre d’info.

Règle :
- l’action ne doit apparaître que si le déplacement est réellement possible

IMPORTANT
Pour décider si le déplacement est possible, réutiliser la logique existante du projet :
- destination valide
- destination découverte
- chemin valide
- pas de traversée interdite
- pas de bouton si la case est la case actuelle du joueur
- pas de duplication fragile de logique si un helper existe déjà

Le comportement au clic doit ouvrir le même flux de confirmation de déplacement que l’existant.
Je ne veux pas un nouveau système de déplacement parallèle.

B. Retirer le bouton `Se déplacer ici` de la fenêtre d’info

Je veux qu’elle s’ouvre au double clic droit.

IMPORTANT

- simple clic droit sur une case → ne doit plus ouvrir la fenêtre d’info
- double clic droit sur une case → ouvre la fenêtre d’info de cette case

Tu dois faire ça proprement, sans casser :
- la prévention du menu contextuel navigateur
