ÉTAPE 3 — BUILDING EFFECTS

Dans buildingEffects.ts :

Convertir les effets de production :

* ironPerTurn + copperPerTurn doivent devenir commonMetalsPerTurn
* furPerTurn doit devenir leatherFurPerTurn
* goldPerTurn doit rester legacy ou être remplacé par fractenPerTurn si encore actif

Règle :

* les nouveaux bâtiments ou effets actifs doivent écrire V2
* les champs V1 peuvent rester en commentaire/fallback si nécessaire
* ne pas écrire V1 et V2 pour la même production logique, sauf sync legacy explicitement documentée

ÉTAPE 4 — ECONOMY SERVICE / PRODUCTION TICK

Dans economyService.ts :

Convertir la lecture de production ville :

Avant :

* city.ironPerTurn
* city.copperPerTurn
* city.furPerTurn

Après :

* city.commonMetalsPerTurn
* city.leatherFurPerTurn

Destination production :

* si ville avec banque : player_bank.common_metals / player_bank.leather_fur
* si ville sans banque : city_pending_harvest.common_metals / city_pending_harvest.leather_fur

Ne plus écrire iron/copper/fur comme source principale.

Fallback acceptable :

* si commonMetalsPerTurn absent ou 0, lire ironPerTurn + copperPerTurn comme fallback
* si leatherFurPerTurn absent ou 0, lire furPerTurn comme fallback
* ne jamais additionner V1 + V2 si V2 existe
