CONTEXTE
Je ne veux pas d’implémentation immédiate.
Je veux un audit d’architecture strict, comparatif, puis une recommandation ferme.

CONTEXTE VALIDÉ
Le modèle actuel semble encore être :
- une action serveur unique `move`
- un `path` complet calculé au départ
- une progression surtout rejouée côté client
- une position réelle qui n’est effectivement validée côté serveur qu’à la fin de l’action

Ce modèle est insuffisant pour le futur du jeu si le déplacement doit pouvoir :
- être interrompu
- être bloqué
- être affecté par un événement
- exposer une case courante réelle
- supporter plus tard des interactions sur une route

DIRECTION CIBLE À ÉVALUER
Je veux que tu audites en priorité une architecture HYBRIDE :

1. Le pathfinder sert uniquement à calculer la route optimale
   - il doit chercher le chemin au coût total PA minimal
   - pas simplement le moins de cases

2. L’exécution du déplacement doit être réellement progressive
   - case par case
   - côté serveur
   - authoritative

3. MAIS
   - je ne veux pas forcément une action DB totalement indépendante par case
   - je veux évaluer un modèle hybride plus propre :
     - une action parent `move`
     - un `path` complet
     - une progression interne par étapes / cases
     - une position réelle serveur mise à jour à chaque case franchie
     - possibilité d’interruption entre deux cases

AUTRES OPTIONS À COMPARER
Tu dois comparer explicitement :

OPTION A — modèle actuel
- une action unique
- path complet
- position réelle seulement à la fin
- client rejoue le trajet

OPTION B — action unique progressive
- une action parent `move`
- path complet
- step courant / progression interne
- position réelle mise à jour case par case
- interruptions possibles entre deux cases

OPTION C — une action DB par case
- le path complet est découpé en micro-actions unitaires
- une case = une action

IMPORTANT
Je veux que l’option B (hybride) soit auditée comme option prioritaire,
mais je veux quand même une vraie comparaison avec A et C.
