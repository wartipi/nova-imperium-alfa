ÉTAPE 2 — AJOUT DB MINIMAL
Dans shared/schema.ts, ajoute une table unique pour l’état global du tour.
Nom recommandé :
- gameClock
ou
- worldClock

Colonnes minimales recommandées :
- id: integer primary key ou singleton simple
- currentTurn: integer not null default 1
- turnDurationHours: integer not null default 24
- turnStartedAt: timestamp not null
- nextTurnAt: timestamp not null
- lastProcessedTurn: integer not null default 0
- updatedAt: timestamp not null defaultNow

IMPORTANT
- structure simple
- une seule ligne active
- pas de complexité inutile
- pas de support multi-mondes
- pas de configuration excessive

ÉTAPE 3 — SERVICE SERVEUR
Créer un service dédié, par exemple :
- server/gameTurnService.ts

Ce service doit fournir au minimum :
1. ensureGameClock()
- garantit qu’une ligne singleton existe
- initialise :
  - currentTurn = 1
  - turnDurationHours = 24
  - turnStartedAt = now
  - nextTurnAt = now + 24h
  - lastProcessedTurn = 0

2. getGameClock()
- retourne l’état courant

3. processDueTurns()
- lit l’heure actuelle
- compare avec nextTurnAt
- si aucun tour n’est dû → ne rien faire
- si un ou plusieurs tours sont dus :
  - les traiter séquentiellement
  - incrémenter currentTurn
  - avancer turnStartedAt et nextTurnAt
  - mettre à jour lastProcessedTurn

IMPORTANT
Pour cette première version :
- rester simple
- calcul déterministe
- pas de logique exotique
- accepter un rattrapage séquentiel si plusieurs tours sont dus

Si le serveur est arrêté 2 ou 3 jours :
- le service doit pouvoir rattraper proprement les tours dus au redémarrage
- sans double traitement du même tour

ÉTAPE 4 — INTÉGRATION AU BOOT SERVEUR
Dans server/index.ts :
- appeler ensureGameClock() au démarrage
- lancer un petit scheduler serveur simple, par exemple un setInterval toutes les 60 secondes
- ce scheduler appelle processDueTurns()

IMPORTANT
- ne pas faire une boucle agressive
- ne pas faire un scheduler complexe
- 60 secondes est suffisant pour un tour de 24h
- priorité à la stabilité
