HYPOTHÈSE À VÉRIFIER

Le bug probable :
- `PixelMapRenderer.ts` utilise seulement `isHexVisible`
- mais côté `usePlayer`, `isHexVisible` peut inclure les tuiles explorées/découvertes
- donc l’immersive dessine les tuiles découvertes comme pleinement visibles
- alors que le strategic applique peut-être une couche de fog séparée ou une opacité sur les tuiles explorées mais non actuellement visibles

Ne pas supposer : vérifier dans le code.

CORRECTION ATTENDUE SI CONFIRMÉE

Si la cause est confirmée, corriger le mode immersive pour gérer trois états :

1. Tuile actuellement visible
   - rendu normal

2. Tuile explorée/découverte mais non actuellement visible
   - rendu atténué / fog overlay / sprite fog partiel
   - ne doit pas afficher d’informations dynamiques cachées
   - ne doit pas afficher les autres joueurs
   - ne doit pas afficher détails actifs réservés à la vision courante

3. Tuile jamais découverte
   - fog complet / masquée
   - aucune ressource
   - aucune unité
   - aucun joueur
   - aucune donnée cachée
