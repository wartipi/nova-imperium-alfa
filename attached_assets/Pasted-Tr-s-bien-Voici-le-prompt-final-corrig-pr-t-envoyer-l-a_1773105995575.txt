# Prompt pour agent IA

## Implémentation de la persistance de position joueur dans le monde

Tu travailles sur **Nova Imperium**.

Le système actuel possède déjà :

* carte persistante PostgreSQL
* carte segmentée **50 × 30**
* chargement dynamique **bloc 3×3**
* cache de segments côté client
* overlay de chargement
* recalibration `originWorldX / originWorldY`
* système d’authentification simple (`auth.ts`)

Actuellement :

* la carte est persistante
* mais **la position du joueur ne l’est pas**

À chaque démarrage :

* le jeu charge `(0,0)`
* trouve une case libre
* place le joueur

Ce comportement doit être remplacé par **une vraie persistance joueur**.

---

# Objectif global

À la fin de cette tâche :

1. la position du joueur est sauvegardée en base
2. le jeu recharge cette position au démarrage
3. le bon bloc de carte est chargé automatiquement
4. le joueur apparaît **exactement au bon endroit**
5. les déplacements mettent à jour la position persistée

---

# Règles strictes

Tu dois respecter ces contraintes :

* ne pas refactorer tout le projet
* ne pas casser le système de carte existant
* ne pas casser le cache de segments
* ne pas casser la recalibration existante
* ne pas modifier l’authentification actuelle
* ne pas corriger les erreurs TypeScript hors périmètre
* rester minimal et compatible prototype

## Étape 1.2 — Ajouter une table dédiée

Créer une table :

```
player_positions
```

Colonnes :

```
player_id TEXT PRIMARY KEY
world_x INTEGER NOT NULL
world_y INTEGER NOT NULL
segment_x INTEGER NOT NULL
segment_y INTEGER NOT NULL
updated_at TIMESTAMP NOT NULL
```

Contraintes :

* `player_id` = identifiant utilisateur
* une seule position par joueur
* pas de dépendance sur `users` autre que la clé

### Pourquoi

On garde la table `users` intacte et extensible.

# PRIORITÉ 2 — Service backend

Créer :

```
server/playerPositionService.ts
```

Fonctions attendues :

```
getPlayerPosition(playerId)
savePlayerPosition(playerId, worldX, worldY)
ensurePlayerPosition(playerId)
```

---

## getPlayerPosition

Retourne :

```
{
 worldX,
 worldY,
 segmentX,
 segmentY
}
```

ou `null`.

---

## savePlayerPosition

Entrée :

```
playerId
worldX
worldY
```

Calculer :

```
segmentX = floor(worldX / 50)
segmentY = floor(worldY / 30)
```

Sauvegarder :

```
worldX
worldY
segmentX
segmentY
updatedAt
```

---

## ensurePlayerPosition

Si aucune position n’existe :

créer **une position déterministe** :

```
worldX = 3
worldY = 3
segmentX = 0
segmentY = 0
```

Pourquoi :

* cohérent avec le prototype
* reproductible
* évite un spawn aléatoire

Retourner ensuite la position.

# PRIORITÉ 5 — Nouveau flux de démarrage

Modifier le démarrage du jeu.

Flux actuel :

```
loadBlockFromDB(0,0)
findLandHex
moveAvatarToHex
```

Ce flux doit être remplacé.

---

## Nouveau flux

1. récupérer position persistée :

```
fetchPlayerPosition()
```

2. obtenir :

```
worldX
worldY
```

3. calculer :

```
segmentX
segmentY
```

4. charger bloc :

```
loadBlockFromDB(segmentX, segmentY)
```

5. attendre fin chargement

6. convertir en coordonnées locales :

```
hexX = worldX - originWorldX
hexY = worldY - originWorldY
```

7. placer joueur :

```
moveAvatarToHex(hexX, hexY)
```

---

## Important

Ne pas casser :

```
originWorldX
originWorldY
```

La conversion doit rester :

```
arrayX = worldX - originWorldX
arrayY = worldY - originWorldY
```

# PRIORITÉ 6 — Sauvegarde pendant le jeu

La position joueur doit être sauvegardée **quand un déplacement logique est terminé**.

---

## Politique de sauvegarde

Sauvegarde principale :

```
fin de déplacement joueur
```

Sauvegarde secondaire :

```
changement de segment
```

Mais :

```
ensurePlayerSegmentLoaded
NE DOIT PAS être l’unique point de sauvegarde
```

---

## Conversion correcte

Avant sauvegarde :

```
worldX = hexX + originWorldX
worldY = hexY + originWorldY
```

Sauvegarder **ces coordonnées monde**.

Jamais :

```
avatarHexPosition
```

directement.
