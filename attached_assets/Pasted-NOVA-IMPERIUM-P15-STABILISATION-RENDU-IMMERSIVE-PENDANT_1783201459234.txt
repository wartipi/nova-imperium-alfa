PROBLÈME OBSERVÉ PAR L’UTILISATEUR

En mode immersive Pixel HD, quand l’utilisateur :
- bouge le curseur
- clique
- déplace la carte
- interagit avec la carte

le rendu immersive / filtre / skin Pixel HD semble être interrompu temporairement.
Le rendu revient ensuite en mode immersive après un court délai.

Hypothèse probable :
- GameEngine.render() redessine immédiatement la vue strategic classique pendant certains événements souris/caméra
- renderPixelHDOverlay() n’est pas rappelé immédiatement après tous ces rendus
- le mode immersive agit comme overlay après strategic, mais certains chemins de rendu ne réappliquent pas l’overlay

OBJECTIF UNIQUE DU BLOC

Stabiliser le mode immersive pour qu’il reste affiché pendant toutes les interactions souris/caméra.

Le mode immersive ne doit plus “flasher” ou retomber brièvement sur le rendu strategic lors des interactions.

QUESTION PRINCIPALE

Quels chemins de rendu appellent GameEngine.render() sans rappeler renderPixelHDOverlay() immédiatement après ?

CORRECTION ATTENDUE

Appliquer la correction minimale et fiable.

Options possibles, à choisir après audit :

OPTION A — Correction côté GameCanvas
- remplacer les appels directs à `gameEngineRef.current.render()` par un wrapper local du type :
  - `renderCurrentMap()`
  - qui appelle d’abord `gameEngineRef.current.render()`
  - puis `renderPixelHDOverlay()`
- utiliser ce wrapper dans tous les chemins de rendu contrôlés par GameCanvas

OPTION B — Callback post-render dans GameEngine
- si GameEngine appelle lui-même `render()` pendant drag/zoom/mouse move sans passer par GameCanvas
- ajouter un callback optionnel minimal :
  - `setPostRenderCallback(callback)`
  - appelé à la fin de `GameEngine.render()`
- GameCanvas configure ce callback pour appeler `renderPixelHDOverlay()` uniquement quand `mapRenderMode === "immersive"`
- attention à éviter les boucles infinies :
  - le callback ne doit pas rappeler `GameEngine.render()`
  - il doit seulement dessiner l’overlay Pixel HD

OPTION C — Autre correction minimale
- seulement si A/B ne sont pas appropriées
- expliquer pourquoi
- garder le scope petit

RÈGLE IMPORTANTE

Le mode immersive est maintenant le mode par défaut.
Toute interaction qui déclenche un rendu strategic doit immédiatement réappliquer le rendu immersive dans la même frame ou le même cycle.

CONTRAINTE ANTI-BOUCLE

Ne jamais créer une boucle :
- GameEngine.render()
- renderPixelHDOverlay()
- GameEngine.render()
- renderPixelHDOverlay()
- etc.

`renderPixelHDOverlay()` doit rester un dessin canvas additionnel, pas un déclencheur de nouveau render strategic.
