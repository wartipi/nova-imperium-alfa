ÉTAPE 2 — MODIFICATION CIBLÉE

Changer uniquement la valeur par défaut.

Comportement requis :

```ts
const savedMode = localStorage.getItem("nova_map_render_mode");

if (savedMode === "strategic" || savedMode === "immersive") {
  return savedMode;
}

return "immersive";
```

Ou équivalent compatible avec le code existant.

Important :

* ne pas écraser le choix localStorage existant
* ne pas forcer immersive à chaque chargement
* ne pas supprimer strategic
* ne pas changer la touche M
* ne pas changer le nom de la clé localStorage
* ne pas changer la structure du renderer
