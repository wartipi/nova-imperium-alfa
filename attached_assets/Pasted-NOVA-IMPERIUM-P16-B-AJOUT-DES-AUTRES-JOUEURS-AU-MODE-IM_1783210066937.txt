SOURCE VALIDÉE PAR P16-A

La source côté client est :

`usePlayerPresence.getState().players`

Chaîne complète :

`usePlayerPresence.getState().players`
← `fetchPlayerPositions()`
← `GET /api/players/positions`
← `getActivePlayerPositions(excludePlayerId, isAdmin)`

Garanties validées :
- le joueur courant est exclu côté serveur
- P14-C filtre côté serveur avec `player_discovered_tiles`
- P14-B filtre côté client avec `isHexVisible`
- les données peuvent être utilisées pour immersive sans fuite de fog si on réutilise la même conversion et le même filtre

COORDONNÉES VALIDÉES

L’API retourne des coordonnées MONDE :
- `worldX`
- `worldY`

La conversion locale utilisée en strategic est :
- `hexX = worldX - originWorldX`
- `hexY = worldY - originWorldY`

Le mode immersive attend des coordonnées locales comme :
- `mapData[y][x]`
- unités
- colonies

P16-B doit réutiliser cette même conversion.
