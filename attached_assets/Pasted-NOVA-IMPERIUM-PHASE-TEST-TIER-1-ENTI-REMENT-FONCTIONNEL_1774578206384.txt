CONTEXTE VALIDÉ

La logistique V1 actuelle existe déjà pour :
- player_bank
- player_transport
- city_pending_harvest
- city_inventory
- transferts banque → ville
- transferts banque → joueur
- collecte physique
- consommation de construction

Mais cette base reste construite autour d’un modèle ancien :
- une case = au plus une ressource
- production serveur réelle encore limitée à goldPerTurn / foodPerTurn

Je veux maintenant que le TIER 1 fonctionne entièrement pour la phase de test.

OBJECTIF DE LA PHASE

Je veux un Tier 1 réellement jouable de bout en bout.

Cela veut dire :

1. une case peut contenir plusieurs ressources
2. les ressources de case Tier 1 existent réellement dans la carte
3. les bâtiments d’exploitation de base peuvent extraire ces ressources
4. l’extraction alimente le pipeline logistique existant
5. les matériaux Tier 1 sont stockables, transférables, collectables et consommables
6. le client n’affiche plus un faux modèle mono-ressource si le serveur passe en multi-ressources
7. gold ne fait plus partie des ressources brutes de case Tier 1

IMPORTANT :
Je ne veux pas seulement un cadrage.
Je veux une implémentation testable du Tier 1 complet.

RÈGLE DE DESIGN À VERROUILLER

Le Tier 1 correspond aux ressources brutes de la carte et à leur exploitation de base.

Le gold NE DOIT PAS être traité comme ressource brute native de case.

Une case peut contenir 0 à plusieurs ressources.

Les cavernes peuvent contenir plusieurs minerais et aussi de l’huile.

POINT 2 — GÉNÉRATION / SEED

Je veux que la génération de carte Tier 1 soit corrigée selon les nouvelles règles :

POINT 3 — MAPPING TIER 1

Je veux que tu définisses clairement le mapping :

resource(s) on tile
→ bâtiment d’exploitation
→ matériau logistique produit

Exemples attendus de logique :
- forest + sawmill → wood
- forest + hunting_post + deer/fur → food / fur
- fertile_land + farm + wheat/cattle → food
- shallow_water + fishing_post + fish → food
- hills / mountains / caves + mine / advanced_mine → stone / iron / copper / coal / oil selon les ressources présentes
- herbs → herbalist_house ou exploitation simple selon ce qui existe déjà

IMPORTANT :
Je veux un mapping réel, cohérent avec le code et le design.
Pas juste une liste théorique.
