- la liste repliable “Colonies fondées” peut rester comme info annexe

IMPLÉMENTATION ATTENDUE

1. Ajouter un état de sélection de ville
- exemple : selectedCityId ou équivalent
- initialisé automatiquement sur la première ville disponible si elle existe

2. Ajouter un menu déroulant visible au-dessus de la zone de construction
- libellé clair du type :
  “Ville sélectionnée”
- chaque option doit contenir au minimum le nom de la ville

3. Remplacer l’affichage multi-cartes actuel

- ne rendre qu’une seule fiche de ville :
  celle sélectionnée dans le dropdown

4. Conserver pour la ville sélectionnée :
- nom de la ville
- contexte d’exploitation
- stock local
- message de construction
- production en cours
- catégories de bâtiments
- boutons Construire
- tooltips

5. Conserver le comportement admin si possible
- si le mode admin a un flux distinct, ne le casse pas
- mais si c’est simple, applique aussi un dropdown côté admin plutôt qu’une liste complète
- priorité : cohérence d’affichage et faible risque
