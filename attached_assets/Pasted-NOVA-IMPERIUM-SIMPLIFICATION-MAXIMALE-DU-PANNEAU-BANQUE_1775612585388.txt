RÔLE
Tu travailles sous contrainte stricte :
audit → diagnostic → correctif minimal → vérification.
Aucun refactor massif.

OBJECTIF
Simplifier fortement TreasuryPanel.tsx pour supprimer le bruit visuel :
- plus d’icônes avec des 0 partout
- plus de rangées fixes de petits inputs
- seulement les ressources réellement disponibles
- un seul pattern UI réutilisable

IMPORTANT
Ne touche pas au backend.
Ne touche pas aux handlers métier.
Ne touche pas aux routes.
Le chantier est purement UI dans :
- client/src/components/game/TreasuryPanel.tsx

DIAGNOSTIC À RESPECTER
1. Le solde banque affiche actuellement une grille fixe avec toutes les ressources.
2. Les sections de transfert/dépôt affichent des AmountInput fixes pour toutes les ressources.
3. Cela crée trop de bruit visuel.
4. La simplification cible est :
   - afficher seulement les ressources disponibles
   - unifier le rendu avec un seul composant de ligne de ressource
   - supprimer la grille fixe et les champs inutiles

OBJECTIF UI EXACT

A. Solde banque
- supprimer complètement la grille de StatBox fixe
- remplacer par un bloc simple :
  - si ressources disponibles :
    afficher une liste compacte de ressources actives seulement
  - si aucune :
    afficher "Aucune ressource en banque"

Format attendu :
- 🪵 Bois · 34
- 🪨 Pierre · 12
- ⚙️ Fer · 6

B. Transférer vers une ville du réseau
- afficher seulement les ressources de banque > 0
- une ligne par ressource visible
- plus aucun champ pour une ressource absente

C. Prendre en transport
- afficher seulement les ressources de banque > 0
- une ligne par ressource visible
- plus aucun champ pour une ressource absente

D. Déposer à la banque
- afficher seulement les ressources de transport > 0
- une ligne par ressource visible
- si transport vide :
  afficher "Aucune ressource à déposer"

ERGONOMIE À APPLIQUER
Créer un composant unique de ligne, par exemple :
- ActiveResourceRow

Chaque ligne doit contenir :
- icône
- nom de la ressource
- quantité disponible
- input quantité
- bouton Max

Format visuel cible :
🪵 Bois · dispo 34 · [input] [Max]

RÈGLES TECHNIQUES
1. créer une source de vérité unique pour les ressources :
   - key
   - icon
   - label
2. créer un helper pour extraire les ressources visibles depuis une source :
   - bank > 0
   - transport > 0
3. supprimer l’usage de AmountInput dans les trois sections
4. remplacer par le composant unique ActiveResourceRow
5. conserver les states existants :
   - toCity
   - toPlayer
   - toBank
6. conserver les handlers existants :
   - handleTransferToCity
   - handleTransferToPlayer
   - handleDepositToBank
7. les ressources non affichées restent implicitement à 0 dans les handlers
