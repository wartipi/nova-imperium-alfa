OBJECTIF P5
Faire un bloc de stabilisation ciblé sur le rendu des terrains immersive.

Le mode immersive doit :

1. afficher les bons terrains aux bonnes coordonnées ;
2. respecter mapData[y][x] ;
3. respecter caméra / zoom / centrage ;
4. ne pas décaler la grille ;
5. ne pas écraser la vue stratégique ;
6. rester fallback-safe ;
7. conserver strategic comme mode par défaut.

ÉTAPE 2 — CORRIGER LA CONVENTION MAPDATA

Confirmer que PixelMapRenderer lit toujours :

mapData[y]?.[x]

et jamais :

mapData[x]?.[y]

Rechercher toutes les occurrences suspectes.

Si une logique utilise encore colonne-major :

* corriger vers ligne-major
* documenter dans un commentaire court

ÉTAPE 3 — STABILISER LA GÉOMÉTRIE

Le rendu immersive doit utiliser la même géométrie que la carte actuelle.

Formule cible :

hexHeight = hexSize * Math.sqrt(3)
screenX = x * hexSize * 1.5 - cameraX
screenY = y * hexHeight + (x % 2) * hexHeight / 2 - cameraY

Mais attention :
Si GameCanvas transmet déjà un hexSizeEffectif ou une caméra transformée par zoom, ne pas appliquer le zoom deux fois.

Objectif :

* pas de double zoom
* pas de double camera offset
* pas de décalage horizontal
* pas de décalage vertical
* alignement visuel cohérent avec le renderer strategic

ÉTAPE 4 — CLARIFIER LES RESPONSABILITÉS DE ZOOM

Dans le code, clarifier qui applique le zoom :

Option recommandée :

* GameCanvas calcule les valeurs finales
* PixelMapRenderer reçoit des valeurs déjà prêtes
* PixelMapRenderer ne recalcule pas une deuxième fois le zoom

Ou inversement si le code actuel est plus propre, mais il faut une seule responsabilité claire.

Ajouter un commentaire court si nécessaire.

ÉTAPE 7 — FOG / VISION

Le mode immersive doit consommer seulement les callbacks existants :

* isHexVisible
* isHexInFogRing

Règles :

* ne pas recalculer la vision dans PixelMapRenderer
* ne pas modifier ResourceRevealSystem
* ne pas modifier usePlayer/useMap sauf nécessité absolue
* si callback absent, afficher terrain sans fog avancé
* si non visible, dessiner fog
* si fog ring, dessiner terrain + voile sombre

ÉTAPE 9 — FALLBACK STRATEGIC

Maintenir le fallback strict :

En mode strategic :

* renderer actuel seulement
* aucune régression

En mode immersive :

* renderer actuel peut rester dessiné dessous
* PixelMapRenderer dessine par-dessus
* try/catch protège l’appel
* si erreur, ne pas écran noir
* log unique ou non-spam
