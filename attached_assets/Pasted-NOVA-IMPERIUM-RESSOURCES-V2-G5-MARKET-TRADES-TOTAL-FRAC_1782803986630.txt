ÉTAPE 4 — BACKFILL NON DESTRUCTIF

Exécuter :

UPDATE market_trades
SET total_fracten = total_gold
WHERE total_fracten = 0
AND total_gold > 0;

Puis vérifier :

SELECT COUNT(*) AS trade_count,
COALESCE(SUM(total_gold), 0) AS total_gold_sum,
COALESCE(SUM(total_fracten), 0) AS total_fracten_sum,
SUM(CASE WHEN total_fracten = total_gold THEN 0 ELSE 1 END) AS mismatches
FROM market_trades;

Résultat attendu :

* mismatches = 0
* total_fracten_sum = total_gold_sum
