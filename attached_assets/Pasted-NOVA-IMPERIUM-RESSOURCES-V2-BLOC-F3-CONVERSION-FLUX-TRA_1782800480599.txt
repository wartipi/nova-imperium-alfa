ÉTAPE 2 — RÈGLES DE CONVERSION

Règle générale :

* V2 est source principale
* V1 est fallback seulement si V2 absent ou égal à 0
* ne jamais additionner V1 + V2 pour une même ressource logique

Conversions :

* gold → fracten
* iron + copper → common_metals
* fur → leather_fur

Pour chaque flux :

* débit V2 ou fallback V1, jamais les deux
* crédit V2 en sortie principale
* les vieux flux V1 peuvent être convertis vers V2 à destination si sécuritaire
* documenter toute compatibilité legacy conservée
