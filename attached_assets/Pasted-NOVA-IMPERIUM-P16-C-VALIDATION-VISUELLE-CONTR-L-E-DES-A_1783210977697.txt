TESTS À EFFECTUER

A. Test baseline

1. Lancer l’application en mode joueur normal.
2. Confirmer que le mode immersive est actif.
3. Confirmer qu’aucune erreur console n’apparaît.
4. Confirmer que `npm run check` reste à 187 erreurs TypeScript préexistantes.

B. Test sans autre joueur

1. Avec un seul joueur actif :
   - vérifier que `GET /api/players/positions` retourne `[]`
   - vérifier qu’aucun marqueur autre joueur n’apparaît
   - vérifier qu’il n’y a pas de doublon de l’avatar local

C. Test avec autre joueur réel ou session secondaire

Si possible :
1. Connecter un deuxième compte ou une deuxième session.
2. Placer l’autre joueur sur une tuile visible/découverte par le joueur test.
3. Vérifier :
   - le marqueur apparaît en mode immersive
   - le username est lisible
   - le marqueur n’est pas trop gros
   - les unités restent visibles
   - les colonies restent visibles
   - le mode strategic affiche toujours les autres joueurs comme avant
   - le toggle strategic/immersive fonctionne

D. Test fog

Si possible :
1. Placer l’autre joueur sur une tuile non découverte / non visible.
2. Vérifier côté API joueur normal :
   - la position ne doit pas être retournée par `/api/players/positions`
   - ou, si retournée pour une raison de synchro particulière, elle doit être masquée côté client par `isHexVisible`
3. Vérifier mode immersive :
   - aucun marqueur hors fog ne doit apparaître
4. Vérifier mode strategic :
   - aucun marqueur hors fog ne doit apparaître

E. Test admin

Si un compte admin est disponible :
1. Vérifier que le bypass admin reste cohérent.
2. L’admin peut voir plus large si c’est déjà le comportement existant.
3. Ne pas modifier ce comportement.

F. Test interactions

En mode immersive avec un autre joueur visible :
1. drag carte
2. zoom
3. clic tuile
4. sélection unité
5. déplacement caméra clavier
6. toggle strategic → immersive → strategic

Vérifier :
- pas de flash strategic
- marqueur autre joueur toujours cohérent
- pas de duplication
- pas d’erreur console
- pas de disparition anormale
