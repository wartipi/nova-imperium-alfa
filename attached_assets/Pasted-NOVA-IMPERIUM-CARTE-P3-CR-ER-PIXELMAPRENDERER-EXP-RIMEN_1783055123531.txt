ÉTAPE 2 — TYPES PUBLICS

Définir des types locaux minimaux.

Le renderer doit consommer une tuile compatible avec les tuiles existantes du jeu.

Créer un type local souple, par exemple :

export interface PixelMapTile {
x?: number;
y?: number;
terrain: string;
resource?: string | null;
discovered?: boolean;
explored?: boolean;
ownerId?: string | number | null;
cityId?: string | number | null;
}

Créer :

export interface PixelMapRenderOptions {
ctx: CanvasRenderingContext2D;
mapData: PixelMapTile[][];
width: number;
height: number;
cameraX: number;
cameraY: number;
hexSize: number;
zoom?: number;
showGrid?: boolean;
animateWater?: boolean;
waterFrame?: 0 | 1;
selected?: { x: number; y: number } | null;
hovered?: { x: number; y: number } | null;
isHexVisible?: (x: number, y: number) => boolean;
isHexInFogRing?: (x: number, y: number) => boolean;
}

ÉTAPE 4 — FONCTIONS GÉOMÉTRIE

Implémenter localement :

* hexToScreen(x, y, hexSize, cameraX, cameraY)
* drawHexPath(ctx, cx, cy, hexSize)
* getVisibleBounds(mapData, width, height, cameraX, cameraY, hexSize)

Utiliser la même géométrie que GameEngine :

hexHeight = hexSize * Math.sqrt(3)
screenX = x * hexSize * 1.5 - cameraX
screenY = y * hexHeight + (x % 2) * hexHeight / 2 - cameraY

ÉTAPE 5 — FONCTION PRINCIPALE

Exporter :

export function renderPixelMap(options: PixelMapRenderOptions): void

Comportement :

1. clear canvas avec fond sombre #0c0a08
2. déterminer les bounds visibles
3. pour chaque tuile visible :

   * vérifier terrain
   * appliquer vision/fog si callbacks fournis
   * dessiner sprite Pixel HD si terrain supporté
   * sinon fallback hex couleur neutre
4. dessiner optionnellement :

   * fog inconnu avec getPixelHDFogSprite()
   * voile fog ring si isHexInFogRing
   * grille si showGrid
   * hover si hovered
   * sélection si selected

Ne pas dessiner encore :

* unités
* colonies
* ownership
* ressources de tuile
* routes
* rivières
* bâtiments
* avatar
* autres joueurs

Ces couches seront pour P6 à P9.

ÉTAPE 6 — VARIANT DÉTERMINISTE

Créer une fonction :

function getTileVariant(x: number, y: number): number

Règle :

* retourner 0, 1, 2 ou 3
* déterministe par coordonnées
* ne pas utiliser Math.random()

Exemple acceptable :

* hash simple basé sur x/y
* variant = hash % 4
