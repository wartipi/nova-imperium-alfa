CONTEXTE

* bank → city

Ressources V2 attendues :

* fracten
* common_metals
* leather_fur

Fallback legacy temporaire :

RISQUES À AUDITER

1. Double débit
   Vérifier qu’un transfert ne débite jamais :

* fracten + gold
* common_metals + iron/copper
* leather_fur + fur

2. Double crédit
   Vérifier qu’une complétion ne crédite jamais :

* fracten + gold
* common_metals + iron/copper
* leather_fur + fur

3. Path d’action
   Vérifier que les actions créées stockent bien les clés V2 :

* fracten
* common_metals
* leather_fur

Et non les anciennes clés principales :

* gold
* iron
* copper
* fur

4. UI TreasuryPanel
   Vérifier que les formulaires envoient bien les champs V2 :

* fracten
* common_metals
* leather_fur

Et que les champs V1 ne sont pas envoyés comme choix principal.

5. API client
   Vérifier que postTransferBankToCity et postTransferBankToPlayer envoient V2 en priorité.
