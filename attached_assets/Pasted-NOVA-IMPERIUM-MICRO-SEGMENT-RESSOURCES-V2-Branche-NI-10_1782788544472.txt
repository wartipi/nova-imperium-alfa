INTERDICTIONS

* Aucun refactor massif
* Aucune suppression de fichiers
* Aucun nettoyage de code mort
* Aucun changement d’architecture
* Aucun changement auth
* Aucun changement frontend non lié aux ressources
* Aucun changement de logique économique complexe si non nécessaire
* Ne pas toucher aux unités, sauf si le code force actuellement une dépendance directe aux ressources
* Ne pas inventer de nouvelles mécaniques
* Ne pas faire de migration risquée sans diagnostic clair

OBJECTIF
Convertir le jeu vers la nouvelle liste officielle de ressources Nova Imperium.

Le but est de remplacer l’ancien catalogue de ressources par un catalogue plus propre, structuré en catégories simples :

1. Communes
2. Stratégiques
3. Rares
4. Magiques
5. Monnaie officielle

IMPORTANT
Les ressources stratégiques ne sont pas des ressources naturelles de carte.
Elles sont produites par bâtiments.
Elles ne doivent pas être générées naturellement sur les tuiles.

La monnaie officielle Fracten n’est pas une ressource naturelle de carte.
Elle remplace Gold/Or comme monnaie principale.

PÉRIMÈTRE AUTORISÉ
Tu peux lire et modifier uniquement les fichiers nécessaires liés à :

* catalogue des ressources
* types de ressources

* affichage des ressources
* inventaire / économie si les clés de ressources y sont codées en dur
* production des bâtiments si les ressources y sont codées en dur
* marché si les anciennes ressources y sont codées en dur

Fichiers probables à auditer :

* shared/schema.ts
* shared/resource constants ou fichiers équivalents s’ils existent
* server/map generation / map service
* server/routes liées aux ressources, marché, économie, bâtiments
* client constants liées aux ressources
* composants UI affichant les ressources
* fichiers contenant les anciennes clés : gold, food, wood, stone, iron, copper, coal, oil, herbs, fur, mana, crystals, etc.

PÉRIMÈTRE INTERDIT

* auth

Les équipements stratégiques représentent des niveaux généraux de matériel.
Ils ne sont pas limités à l’infanterie, ni aux armes.
Ils couvrent :

* outils
* armes
* armures
* matériel de campagne
* logistique
* entraînement
* soutien opérationnel
* préparation d’unités ou de campagnes

RESSOURCES À RETIRER / REMPLACER

Retirer ou remplacer les anciennes ressources suivantes :

* wheat / Blé → remplacé par food / Nourriture
* fish / Poisson → fusionné dans food / Nourriture
* cattle / Bétail → remplacé par leather_fur / Cuir et fourrure
* iron / Fer → remplacé par common_metals / Métaux communs
* copper / Cuivre → remplacé par common_metals / Métaux communs
* gold / Or comme monnaie → remplacé par fracten / Fracten
* gold / Or comme ressource rare → remplacé par rare_metals_alloys / Métaux et alliages rares
* uranium / Uranium → supprimé
* silk / Soie → remplacé par textiles / Textiles
* oil affiché comme Pétrole → afficher Huile
* ivory / Ivoire → supprimé
* dragon_scales / Écailles de dragon → supprimé
* phoenix_feathers / Plumes de phénix → supprimé
* mana_stones / Pierres de mana → supprimé, redondance avec mana_crystals
* gems / Gemmes → remplacer par precious_stones / Pierres précieuses ou conserver l’ID gems seulement si nécessaire pour compatibilité, mais afficher Pierres précieuses
* siege_equipment / Équipement de siège → ne plus utiliser comme ressource stratégique dans cette version

CAS SPÉCIAL : COMPATIBILITÉ
Si certaines anciennes clés sont profondément utilisées dans le code et que les remplacer directement crée trop de risque, appliquer une stratégie minimale :

1. Garder temporairement l’ancienne clé interne.
2. Changer le nom affiché.
3. Ajouter un commentaire TODO clair pour migration ultérieure.
4. Ne pas faire de migration massive dans ce segment.

Exemples acceptables :

* oil peut rester ID interne oil, affiché Huile.
* gems peut rester ID interne gems si nécessaire, affiché Pierres précieuses.
* gold peut temporairement rester comme clé monétaire seulement si le remplacement direct par fracten est trop risqué, mais l’UI doit afficher Fracten et un TODO doit documenter la dette.

Cependant, si le remplacement est simple et localisé, utiliser directement les nouveaux IDs officiels.

RÈGLES ÉCONOMIQUES MINIMALES

Si le système économique actuel contient encore les ressources :

* gold
* iron
* copper
* fur
* mana

Ne pas forcer une migration complète si cela casse trop de choses.

Appliquer plutôt un correctif minimal :

* gold affiché comme Fracten, ou remplacé par fracten si simple
* iron/copper convertis ou remplacés par common_metals si simple
* fur converti ou remplacé par leather_fur si simple
* mana ne doit pas remplacer automatiquement les ressources magiques sans diagnostic

Si une conversion temporaire est nécessaire :

* wheat, fish → food
* cattle, fur → leather_fur
* iron, copper → common_metals
* gold monnaie → fracten
* gold ressource rare → rare_metals_alloys
* silk → textiles
* gems → precious_stones
* petroleum/pétrole → oil affiché Huile
* mana_stones → mana_crystals ou suppression selon contexte
