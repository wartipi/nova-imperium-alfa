OBJECTIF P10
Auditer le rendu immersive complet avant de poursuivre.

Le but est d’éviter d’empiler routes/rivières/avatar/autres joueurs sur une base visuelle qui aurait :

* trop de bruit visuel
* des couches mal ordonnées
* des couleurs illisibles
* des problèmes de fog
* des problèmes de zoom/caméra
* des unités cachées
* des marqueurs qui se chevauchent trop

PÉRIMÈTRE AUTORISÉ

Modifier seulement si nécessaire :

* client/src/lib/game/PixelMapRenderer.ts
* client/src/components/game/GameCanvas.tsx

Modifications autorisées :

* ajustements visuels mineurs
* ordre de couches si problème constaté
* alpha / opacité
* taille des marqueurs
* positionnement mineur
* commentaires explicatifs
* garde-fous anti-crash
* correction de bug strictement lié au rendu immersive

Ne pas modifier :

* DB
* backend
* schema
* MapGenerator.ts
* mapAdapter.ts
* TerrainCosts.ts
* ResourceRevealSystem.ts
* UnifiedTerritorySystem.ts
* économie
* pathfinding
* exploration
* ownership logic
* unités logic
* mouvement
* combat
* règles de colonie
* règles de ressources

Ne pas ajouter :

* routes
* rivières
* avatar
* autres joueurs
* animation de déplacement
* nouvelle UI majeure
* nouveau système de rendu

ÉTAPE 1 — AUDIT DU PIPELINE DE RENDU

Inspecter PixelMapRenderer.ts.

Vérifier l’ordre réel des couches :

1. Fond canvas
2. Terrain Pixel HD
3. Ownership overlay léger
4. Fog total
5. Fog ring overlay
6. Grille
7. Frontières ownership
8. Ressources de tuile
9. Colonies
10. Bâtiments
11. Unités
12. Sélection tuile

Confirmer :

* fog total masque bien toutes les couches sensibles
* sélection reste au-dessus
* unités restent visibles sans cacher toute la case
* frontières ne dominent pas le terrain
* ressources ne masquent pas colonies/bâtiments
* colonies/bâtiments ne masquent pas les unités

ÉTAPE 2 — AUDIT VISIBILITÉ / FOG

Vérifier que le mode immersive ne révèle rien de caché :

* pas de ressource sous fog total
* pas de colonie sous fog total
* pas de bâtiment sous fog total
* pas d’unité sous fog total
* pas d’ownership sous fog total
* pas de frontière qui révèle un propriétaire caché

Si une fuite visuelle est trouvée :

* corriger dans PixelMapRenderer.ts
* ne pas modifier la logique exploration

ÉTAPE 3 — AUDIT LISIBILITÉ

Vérifier visuellement ou par revue de code :

* ressources assez petites mais lisibles
* unités lisibles au zoom moyen
* unités différenciables par type
* colonies et bâtiments visibles mais pas trop gros
* ownership overlay assez discret
* frontières visibles sans être agressives
* sélection de tuile toujours claire
* mode strategic inchangé

Si nécessaire, ajuster :

* alpha
* taille
* contour
* position des marqueurs
* ordre local de dessin

ÉTAPE 4 — AUDIT ZOOM / CAMÉRA

Vérifier :

* pas de double zoom
* pas de décalage par rapport au mode strategic
* caméra stable
* changement de mode strategic ↔ immersive sans saut visible majeur
* localStorage persiste le mode

Ne pas modifier la logique caméra, sauf correction de rendu strictement nécessaire.

ÉTAPE 5 — AUDIT PERFORMANCE

Faire une revue simple :

* pas de requestAnimationFrame massif ajouté
* pas de recalcul lourd inutile par tuile
* pas de log spam
* sprite cache PixelHDAssets toujours utilisé
* pas de création excessive d’objets évitable dans les couches répétitives

Si un micro-ajustement simple est évident :

* l’appliquer
  Sinon :
* documenter comme limite future
