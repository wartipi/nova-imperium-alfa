OBJECTIF GLOBAL
Unifier le système de pathfinding, d’affichage du trajet, et de confirmation de déplacement pour qu’il soit cohérent entre :
- preview carte
- preview modale
- déplacement serveur autoritaire
- affichage pendant action active

DIAGNOSTIC DE DÉPART — À CONSIDÉRER COMME BASE DE TRAVAIL
Le projet a actuellement plusieurs couches pathfinding / trajet :

1. Preview client modale
- `MovementConfirmationModal.tsx` recalcule un chemin avec `MovementSystem.previewMovement(...)`

2. Preview client carte
- `GameCanvas.tsx` recalcule aussi un preview via `MovementSystem.previewMovement(...)`
- puis construit `previewPathHexes`

3. Path serveur autoritaire
- `GameCanvas.tsx` soumet le déplacement avec `requestMove(...)`
- `server/routes/playerActions.ts` recalcule le chemin via `HexPathfindingServer.findPath(...)`

4. Ancien système local encore présent
- `MovementSystem.planAndExecuteMovement()`
- `executeAnimatedMovement()`

PROBLÈME
Le système n’est pas totalement unifié :
- plusieurs calculs de preview
- plusieurs sources de vérité selon le moment
- code legacy encore présent
- risque de divergence entre preview client et chemin serveur final

TÂCHE 1 — Unifier la source du trajet affiché dans `GameCanvas.tsx`
OBJECTIF
Faire en sorte que la carte affiche une seule source de trajet :
- avant confirmation : trajet basé sur `pendingMovement`
- après confirmation / pendant action active : trajet basé sur `activeAction.path`
- sinon : aucun trajet

BUT CONCRET
Créer une source unifiée du type :
- `pathHexesToRender`

Priorité :
1. si `pendingMovement` existe → afficher le preview
2. sinon si `activeAction.type === "move"` et `status === "in_progress"` → afficher le trajet restant basé sur `activeAction.path`
3. sinon → tableau vide

IMPORTANT
- convertir `activeAction.path` en coordonnées locales
- afficher le trajet restant, pas les cases déjà parcourues
- ne pas modifier `GameEngine.ts` dans cette tâche sauf bug bloquant imprévu
- le but ici est d’unifier la source envoyée au moteur

PÉRIMÈTRE ATTENDU TÂCHE 1
Modifier uniquement :
