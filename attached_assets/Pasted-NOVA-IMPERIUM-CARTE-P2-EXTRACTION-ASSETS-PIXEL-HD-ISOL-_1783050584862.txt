NOVA IMPERIUM — CARTE — P2 / EXTRACTION ASSETS PIXEL HD ISOLÉS
Branche : NI-10.09

OBJECTIF
Extraire le prototype Pixel HD 16 terrains dans un ou plusieurs fichiers isolés, sans l’activer dans le rendu actuel.

Ce bloc prépare l’intégration future du renderer Pixel HD, mais ne doit pas remplacer la carte actuelle.

Ne pas modifier le GameEngine actuel.
Ne pas modifier la génération de monde.
Ne pas modifier la DB.
Ne pas modifier les ressources économiques.
Ne pas ajouter de toggle encore.
Ne pas rendre la carte avec ces sprites maintenant.

CONTEXTE
P1 validé :

* géométrie compatible avec GameEngine
* 15/15 terrains actuels couverts
* renderer isolé recommandé
* approche progressive P2 → P11

Prototype Pixel HD :

* 16 terrains
* sprites 56×49 texels
* palettes riches 7–12 teintes
* éclairage haut-gauche
* détails individuels
* cache terrain|variant|frame
* eau animée 2 frames
* fog sprite
* ressources terrain pixelisées

ÉTAPE 3 — API PUBLIQUE

La fonction principale doit être :

getPixelHDSprite(
terrain: PixelHDTerrain,
variant?: number,
frame?: 0 | 1
): HTMLCanvasElement

Règles :

* variant par défaut : 0
* frame par défaut : 0
* clé cache : terrain|variant|frame
* si terrain inconnu impossible en TypeScript
* ne pas dépendre de React
* ne pas dépendre du GameEngine

Fog :

getPixelHDFogSprite(): HTMLCanvasElement

ÉTAPE 4 — DÉTERMINISME

Chaque sprite doit être déterministe :

* même terrain
* même variant
* même frame
  = même rendu

Utiliser la logique RNG du prototype.
