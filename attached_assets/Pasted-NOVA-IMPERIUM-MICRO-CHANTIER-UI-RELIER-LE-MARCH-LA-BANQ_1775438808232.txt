OBJECTIF
Je veux améliorer le panneau du marché (`PublicMarketplace`) avec 2 ajouts :

1. Si le point d’accès actuel possède aussi une Banque, je veux un accès direct vers la Banque depuis le marché.
2. Je veux une fenêtre / section visible dans le marché qui affiche l’inventaire du joueur.

IMPORTANT
Le but n’est pas de refondre le système.
Le but est d’ajouter ces deux capacités dans le panneau marché existant.

CONTEXTE VÉRIFIÉ
Dans `client/src/components/game/PublicMarketplace.tsx` :
- le panneau vérifie déjà l’accès marché via `/api/market/access-check`
- il charge déjà le carnet, les ordres et les trades
- il ne sait pas encore si une banque est aussi accessible
- il n’affiche pas encore l’inventaire du joueur

Dans `client/src/components/game/TreasuryPanel.tsx` :
- l’accès banque existe déjà séparément
- `getPlayerTransport()` existe déjà dans `economyApi.ts`
- `getPlayerBank()` existe déjà aussi

Dans `client/src/components/game/MedievalHUD.tsx` :
- `nova:open-panel` ouvre déjà les panneaux
- `marketplace` et `treasury` existent déjà comme panneaux

1. afficher un raccourci Banque si la Banque est aussi accessible au point d’accès actuel
