---
name: Nova Imperium CLAUDE.md workflow
description: When and how CLAUDE.md must be updated during Nova Imperium work
---

CLAUDE.md must be updated as part of finishing every bloc/modification in this project — not deferred, not batched at the end of a session.

**Why:** explicit user instruction ("tu dois toujours documenter claude md après chaque modification, enregistre ça dans tes méthodes de travail") after a bloc (Ressources V3-B) was implemented and reported as done without the CLAUDE.md entry, requiring a follow-up correction.

**How to apply:** before declaring any bloc/task complete in this repo, write its CLAUDE.md section (objectif, fichiers touchés, vérifications, diff summary, statut) in the same turn as the code change — never leave it for "later" or a future prompt, even if the user seems to be moving fast through several blocs in a row.
